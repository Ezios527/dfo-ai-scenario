# ИИ-сценарист будущего Дальнего Востока

RAG-система для генерации сценариев развития макрорегиона на основе открытых данных и GigaChat.

## Стек
- Python, Streamlit
- ChromaDB + sentence-transformers (paraphrase-multilingual-MiniLM-L12-v2)
- GigaChat API (Sber)

## Установка
1. Клонировать репозиторий: `git clone ...`
2. Установить зависимости: `pip install -r requirements.txt`
3. Скопировать `.env.example` в `.env` и вставить свой ключ GigaChat.
4. Загрузить данные в ChromaDB (один раз при первом запуске): `python chroma_loader.py`

## Запуск
Дважды кликните по файлу `start_app.bat` в корне проекта.
Откроется окно консоли, приложение запустится, и через несколько секунд браузер автоматически откроет интерфейс по адресу http://localhost:8501.
Если браузер не открылся автоматически — перейдите по ссылке вручную.

## Остановка приложения
Закройте окно консоли, которое открылось при запуске `start_app.bat`, или нажмите Ctrl+C в этом окне.

## Источники данных
Росстат, КРДВ, EastRussia, GxP News и др.
